# Friday — Hidden modes and the cost of access

**A small magnetic graph contains 15 internal modes that its connecting nodes cannot read or write. Changing the outer phases leaves them hidden. Changing an internal phase exposes them, but mathematical visibility arrives before reliable readability.**

This repository records a concrete result from a discussion that began with a claimed proof about π, passed through Fourier flowers and irrational rotations, and reached a more useful question:

> Which distinctions can a system preserve, which can its interface expose, and what operation changes the answer?

The main text is [**What survives, what can be read**](docs/what-survives.md). It develops the mathematical argument, its connection to the π manuscript, and the limits of the memory interpretation.

This is a reproducible research note about a 30-node toy. It is not a trained model, a new theorem about π, or a demonstrated memory device. The underlying ideas belong to established spectral graph theory and control theory. The contribution here is to identify and explain the exact mechanism in this graph, then measure how access changes.

## What the graph actually contains

Five six-node rings are joined through one node per ring. Each internal ring has total magnetic phase π modulo 2π. It is frustrated, despite the original script's description of its internal edges as resonant.

Each ring supports three modes with zero amplitude at its connecting node. Their eigenvalues are

$$
2-\sqrt3,\qquad 2,\qquad 2+\sqrt3.
$$

There are five independent copies of each: **15 hidden modes**. Their survival explains both the unchanged smallest eigenvalue and the 12 repeated-eigenvalue gaps in the golden-angle configuration:

$$
\lambda_{\min}=2-\sqrt3,\qquad 12=3(5-1).
$$

These are structural facts, not evidence that an irrational angle provides extra information capacity. The [derivation](docs/what-survives.md#2-an-explicit-basis-for-the-hidden-modes) gives a closed-form basis, which the audit checks without using an eigensolver to construct it.

## What an observer can recover

The original script computes only a matrix spectrum. This audit additionally specifies a linear state evolution and ideal sensors that read **complex node amplitudes**. For continuous-time evolution generated by `-i L`, the observable dimensions are:

| Sensor placement | Original rational outer phases | Golden outer phases | Rational outer phases using 1/11 turns |
|---|---:|---:|---:|
| Five connecting nodes | 15 / 30 | 15 / 30 | 15 / 30 |
| One adjacent interior node per ring | 27 / 30 | 30 / 30 | 30 / 30 |
| Both sets of nodes | 30 / 30 | 30 / 30 | 30 / 30 |

Here “rational” refers to rational fractions of a full turn. The rational control uses outer phases `2π(c+1)/11`; it does not approximate the golden configuration.

The golden choice improves one sensor arrangement. A rational choice does too. Neither makes the hidden modes visible at the connecting nodes.

## Opening an internal connection

With golden outer phases fixed, add the same offset δ to the first internal edge of every ring. Keep the same five connecting-node sensors. For 80 samples at time spacing 0.37:

| δ, radians | Observable dimensions | Smallest normalized observation singular value |
|---|---:|---:|
| 0 | 15 / 30 | 0, up to roundoff |
| 0.0001 | 30 / 30 | 0.00000725 |
| 0.01 | 30 / 30 | 0.000725 |
| 0.1 | 30 / 30 | 0.00725 |

The observation stack is divided by √80. Full rank is not a noise-performance result: the weakest visible direction can still be extremely weak. These results specify complex amplitudes and ideal unitary evolution; they do not apply unchanged to intensity-only sensors, diffusion, or unknown material parameters.

## Reproduce

Python 3.10+ and NumPy; CPU only. From this directory:

```bash
python -m pip install -r requirements.txt
python audit.py --output results/audit.json
python -m unittest -v
```

On Windows, `python3.13` can replace `python` if that is your installed command. The committed [JSON report](results/audit.json) records the runtime versions, tolerances, and protocol. Floating-point residuals can differ across machines.

## The points worth carrying forward

1. **Symmetry organizes and hides.** A common structure can coordinate many components while making some internal distinctions disappear at an interface.
2. **Access belongs to the system plus its permitted operations.** More frequencies do not reveal a mode that is dark at every frequency. A suitable change in coupling can.
3. **Being distinct, being observable, and being robustly readable are separate properties.** Rank addresses only part of the problem.
4. **Isolation is not retention.** These modes persist in ideal unitary dynamics, but decay under `dx/dt = -Lx`. Their hiddenness alone supplies no durable memory.
5. **A useful memory needs a controlled path between protection and access.** Opening a path is demonstrated here; writing, retaining, and retrieving a payload without unacceptable disturbance are not.
